# Aula Viva · Cultivándonos

Página del proyecto comunitario *Cultivándonos* en el Aula Viva — La Chagra.

Sitio estático (HTML, CSS y JS, sin dependencias). Para publicarlo con GitHub Pages:
Settings → Pages → Deploy from a branch → `main` / `(root)`.

- `index.html` — la página
- `assets/styles.css`, `assets/main.js` — estilos e interacciones
- `assets/img`, `assets/md`, `assets/thumb` — fotografías (grande, mediana, miniatura)
- `assets/fonts` — tipografías Fraunces, Lora y Caveat (SIL Open Font License)
- `assets/Cultivandonos_Chagra.pdf` — la presentación original
